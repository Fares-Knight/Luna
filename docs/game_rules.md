# Règles de Coupe Fleur

Le texte fourni pour **Coupe Fleur** est conservé intégralement dans
[RULES.md](../RULES.md), à la racine du projet. Il constitue la référence des
règles du projet, complétée par les [décisions v0.1](v0_1_decisions.md), qui
priment sur les passages concernés, notamment pour les égalités de proximité.

## Origine et références

Luna reprend les règles du jeu de société **Lacuna** dans une adaptation
numérique indépendante appelée **Coupe Fleur**. Lacuna a été conçu par
**Mark Gerrits**, édité par **CMYK** et publié en français par **SAVANA**.

- [Lacuna — page officielle CMYK](https://www.cmyk.games/products/lacuna).
- [Lacuna — édition française SAVANA](https://savana-games.eu/products/lacuna-fr).
- [Livret français Lacuna, édition SAVANA © 2024](https://latuiledejeu.com/regles/lacuna.pdf) :
  copie hébergée par **La Tuile de Jeu**. Les numéros ci-dessous correspondent
  aux pages imprimées du livret, distinctes des 12 pages du fichier PDF.
  Mark Gerrits y est crédité comme concepteur page 22.

## Variantes connues de Luna

Cette comparaison est limitée aux trois différences ci-dessous ; elle n'est
pas un relevé exhaustif de toutes les adaptations numériques. Les références
pour le comportement implémenté restent `RULES.md` et les décisions v0.1.

| Point | Lacuna, livret français | Luna / Coupe Fleur |
| --- | --- | --- |
| Pions par joueur | Six pions (pages 4–6) | Sept ciseaux par joueur |
| Premier joueur et première fleur | Premier joueur tiré au sort, qui choisit une fleur (pages 4–6) | Joueur 1 commence et reçoit une fleur au hasard |
| Égalité de proximité | Comparer le deuxième pion le plus proche de chaque joueur, puis les suivants si nécessaire (page 18) | Attribuer la fleur au hasard entre les joueurs concernés, puis continuer |

Ces variantes documentent les règles déjà retenues pour Luna ; elles ne changent
ni le texte fourni dans `RULES.md`, ni les décisions v0.1, ni le code du jeu.
